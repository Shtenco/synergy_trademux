# Customer pilot — SYNERGY TradeMux

Objective: build a cost/risk-aware multi-venue execution plan and, where separately approved, dispatch through a gated adapter in customer UAT with measurable execution-planning acceptance criteria.

Phases: frozen quote/use-case scope → isolated UAT → routing-plan evidence → sandbox/paper adapter tests → resilience/load → bounded canary review.

Final report records revision, config, venue permissions, planned vs observed costs, failures, audit evidence and customer decision. Technology acceptance does not imply better fills or profitability.
